# 🍕 Pizza Sales Analysis - SQL & Excel Dashboard

## 📊 Project Overview
Performed complete end-to-end analysis on 1 year (2015) of pizza sales data containing **48,620 rows** and **21,350 orders** using only **SQL + Excel** (no Power BI).

## 🔧 Tools Used
- SQL (MySQL / PostgreSQL)
- Microsoft Excel (Pivot Tables, Charts, Dashboard)

## 📈 Key Business Insights Discovered
- Total Revenue: **$817,860**
- Total Pizzas Sold: **49,574**
- Total Orders: **21,350**
- Average Order Value: **$38.32**
- Peak Month: July (highest revenue)
- Best-Selling Pizza: The Classic Deluxe Pizza
- Peak Hours: 12 PM & 6 PM

## 📂 Project Files
- `pizza_sales_analysis.sql` → All SQL queries (CTEs, window functions, date functions)
- `Pizza_Sales_Dashboard.xlsx` → Complete Excel dashboard with interactive pivot charts
- `dashboard_preview.png` → Screenshot of final Excel dashboard

## 🚀 Skills Demonstrated
- Advanced SQL (Joins, Aggregations, Window functions, Date grouping)
- Data cleaning and analysis using only SQL
- Building fully interactive dashboards in Excel (slicers, pivot tables, dynamic charts)
- 100% tool-independent analysis (no Power BI/Tableau needed)
